# Main FastAPI Application — Router Integration

## 1. Is file ka purpose

`backend/app/main.py` AU Hub ke FastAPI backend ka entry point hai.

Is file mein:
- FastAPI application create hoti hai.
- Application ka title, description aur version set hote hain.
- Authentication router register hota hai.
- Root endpoint API ka basic response deta hai.
- Health endpoint database connection check karta hai.

Jab hum command run karte hain:

```powershell
python -m uvicorn backend.app.main:app --reload
```

Uvicorn `backend.app.main` module ke andar `app` object ko load karta hai.

## 2. FastAPI imports

```python
from fastapi import FastAPI, status
from fastapi.responses import JSONResponse
```

`FastAPI` application create karta hai.

`status` HTTP status constants provide karta hai, jaise `HTTP_503_SERVICE_UNAVAILABLE`.

`JSONResponse` JSON response ko custom HTTP status code ke saath return karne ke liye use hota hai.

## 3. Configuration imports

```python
from backend.app.core.config import (
    API_PREFIX,
    APP_NAME,
    APP_VERSION,
)
```

Ye values configuration file se import hoti hain.

- `API_PREFIX` ki value `/api/v1` hai.
- `APP_NAME` ki value `AU Hub` hai.
- `APP_VERSION` ki value `0.1.0` hai.

Configuration ko ek central file mein rakhne se application ke different parts mein same values dobara define nahi karni padti.

## 4. Database connection check

```python
from backend.app.db.connection import check_database_connection
```

Ye function database module se import hota hai. Health endpoint ise call karke check karta hai ki database query successfully execute ho rahi hai ya nahi.

## 5. Authentication router import

```python
from backend.app.routes.auth import router as auth_router
```

`auth.py` file mein router ka variable `router` naam se defined hai.

`as auth_router` import ke waqt us variable ko `auth_router` naam deta hai. Isse main application mein router ka purpose clearly samajh aata hai.

## 6. FastAPI application creation

```python
app = FastAPI(
    title=f"{APP_NAME} API",
    description=(
        "Learning, collaboration, academic resources, "
        "quizzes, and machine learning for the "
        "Amrapali University community."
    ),
    version=APP_VERSION,
)
```

`FastAPI()` application object create karta hai.

`title` Swagger documentation mein API ka naam dikhata hai. F-string se `APP_NAME` ke saath `API` add hota hai.

`description` API ka purpose explain karta hai.

`version` application version set karta hai. Ye project version metadata hai; automatically package ya database version change nahi karta.

## 7. Router registration

```python
app.include_router(
    auth_router,
    prefix=API_PREFIX,
)
```

Ye is file ka main change hai.

`include_router()` authentication router ke endpoints ko main application mein register karta hai.

Authentication router mein pehle se `prefix="/auth"` defined hai. Main application `API_PREFIX="/api/v1"` add karta hai.

Isliye final route:

`/api/v1` + `/auth` + `/register`

Final endpoint:

`POST /api/v1/auth/register`

Agar router ko include nahi kiya jaye, toh `auth.py` mein endpoint define hone ke bawajood woh main application mein available nahi hoga.

## 8. Root endpoint

```python
@app.get("/")
def root():
    return {
        "success": True,
        "message": "AU Hub API is running.",
    }
```

`@app.get("/")` root URL ke liye GET endpoint register karta hai.

Function dictionary return karta hai, jise FastAPI JSON response mein convert karta hai.

Ye basic check hai ki API respond kar rahi hai; isse database ki health confirm nahi hoti.

## 9. Health endpoint

```python
@app.get("/health")
def health_check():
    database_healthy = check_database_connection()
```

Health endpoint database connection check karta hai aur result ko `database_healthy` variable mein rakhta hai.

```python
if not database_healthy:
```

Agar database check fail hota hai, toh unhealthy response return hota hai.

```python
return JSONResponse(
    status_code=status.HTTP_503_SERVICE_UNAVAILABLE,
    content={
        "status": "unhealthy",
        "service": "au-hub-api",
        "database": "disconnected",
    },
)
```

HTTP `503 Service Unavailable` indicate karta hai ki service is waqt required dependency ke saath kaam nahi kar paa rahi.

```python
return {
    "status": "healthy",
    "service": "au-hub-api",
    "database": "connected",
}
```

Agar database check successful hai, toh health endpoint healthy response deta hai.
